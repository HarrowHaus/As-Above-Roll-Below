# Research Corpus Inventory

**Stage:** discovery inventory, not factual authority.

This file records useful source families already present in the project owner's research corpus. These sources are used to discover vocabulary, references, recurring motifs, and comedy structures. Real-world claims still require independent verification before becoming game canon.

## Corpus roles

For As Above, Roll Below, the corpus should be mined into distinct lanes rather than one undifferentiated “conspiracy” blob.

### Folklore / encounter lane
- cryptids
- hauntings
- regional legends
- witness-story vocabulary
- high strangeness

### Esoteric-history lane
- named traditions
- initiatory groups
- texts
- ritual terminology
- historical occult revival movements

### Conspiracy-lore lane
- recurring theories
- intelligence vocabulary
- secret-program mythology
- hidden-symbolism culture
- numerology / synchronicity

### Institutional / parapolitical lane
- documented organizations
- historical programs
- archives
- bureaucratic terminology
- real public objects/locations that accumulated lore

### Comedy lane
- dead-serious overstatement
- obscene specificity
- treating low-status mundane objects as cosmically important
- escalating a real reference into an original absurdity
- refusing to stop and explain the joke

## Extraction fields

For each episode/transcript candidate, extract:

1. canonical names;
2. aliases/nicknames;
3. locations;
4. organizations;
5. creatures/entities;
6. physical objects;
7. texts/books/documents;
8. recurring verbs and phrases;
9. historical claims;
10. folklore claims;
11. conspiracy claims;
12. comic constructions;
13. visual hooks;
14. mechanic hooks;
15. leads requiring external verification.

## Rule

**Corpus appearance is evidence of cultural relevance, not evidence that the underlying claim is true.**

A candidate only graduates into the game's verified reference database after the source/provenance process in `../CONTENT_RESEARCH_BIBLE.md` is satisfied.
