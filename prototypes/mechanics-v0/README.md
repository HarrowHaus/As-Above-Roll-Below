# Mechanics Prototype v0 — Archived

This directory preserves the original **ROLL / LOOT / REGRET** single-file browser demo that proved the first version of the central interaction:

> roll four d6 → select exactly two to fight → the two left behind become loot.

## Important

This prototype is **superseded**.

It uses the old fixed-Threat / level / lives / CHEAT-token model and does **not** represent the current As Above, Roll Below combat design.

The current design uses:

- monster visible dice rolls;
- deterministic monster Instinct locking;
- player 4d6 / choose 2;
- contested totals;
- winning-margin HP damage;
- numerical HP for both sides;
- build-granted manipulation rather than a universal CHEAT button.

The prototype remains useful as historical evidence that the fundamental `four dice / choose two / leftovers matter` interaction was playable before the larger game was designed.

See `../../docs/GAME_DESIGN_BIBLE.md` and `../../docs/COMBAT_MODEL.md` for current canon.
