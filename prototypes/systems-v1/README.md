# Systems Demo V1

Purpose: validate the run systems beneath the art layer before full vertical-slice environment/menu production.

This prototype tests:

- contested visible dice combat;
- Best Successful Spoils tracking;
- four Spoils quality bands;
- three-offer Loot Drafts;
- Gear / Artifact / Contraband inventory roles;
- inventory replacement/salvage pressure;
- XP and Player Level;
- +2 Max HP / heal 2 level progression;
- Level 3 character Technique choice;
- Coins;
- a simple Shop;
- Elite +1 reward-band elevation;
- acquired-item effects feeding back into later dice decisions.

The current chat build is intentionally self-contained and reuses a minimal enemy-art pool. It is a systems laboratory, not the final Floor I implementation.

Canonical rules are documented in `docs/SYSTEMS_ARCHITECTURE.md` and `docs/VERTICAL_SLICE_CONTENT.md`.
